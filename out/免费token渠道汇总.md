## 详细领取引导

### GitHub Student Developer Pack

- **官网**：https://education.github.com/pack
- **领取页**：https://education.github.com/discount_requests/application
- **文档**：https://docs.github.com/education
- **免费额度**：100+ 合作方权益：GitHub Pro（3000 Actions 分钟 + 180 Codespaces 小时/月）、JetBrains 全家桶、DigitalOcean $200 credits、Azure $100 credits + 免费服务、MongoDB Atlas $50、Namecheap 免费 .me 域名 1 年、Canva Pro、Notion、DataCamp 3 个月、Frontend Masters 6 个月、Datadog Pro 2 年、Sentry、1Password 等
- **有效期**：在校期间持续有效，需每年重新验证；各合作方权益有各自的时限
- **重置规则**：按合作方策略
- **门槛**：无需信用卡｜需要国际网络｜需要实名｜仅限学生

**注册步骤**

1. 准备材料（二选一）：学校签发的邮箱（.edu / .edu.cn / .ac.cn 等），或带日期的在读证明（学生证正面照、学费收据、录取通知书、成绩单）
2. GitHub 账号 Settings → Emails 添加学校邮箱并完成验证（有校园邮箱的走这条最快）
3. 把 GitHub 个人资料的姓名填成与学生证一致的真名，地址填学校所在城市

**领取额度 / 获取 Key**

1. 访问 https://education.github.com/discount_requests/application ，点击「Get student benefits」
2. 身份选 Student，选择你的学校（列表里没有就手动输入全称）
3. 上传证明材料：证件照要清晰、未裁剪、未加滤镜，姓名/学校/当前学年三要素齐全
4. 提交后一般数小时至 72 小时出结果（高峰期可能 1~2 周）
5. 通过后到 https://education.github.com/pack 逐项「Get access」领取

**调用说明**：GitHub 个人主页会出现学生标识；Settings → Billing 显示 Pro

**实用建议**

- 领取顺序有讲究：先领长期型（GitHub Pro、JetBrains——两者在校期间一直有效），限时型（DigitalOcean $200 一年、DataCamp 3 个月、GitKraken 6 个月）等真正要用时再点，别浪费倒计时
- JetBrains 要到 JetBrains 官网申请、验证方式选 GitHub，不是在 GitHub 页面领
- 毕业后 JetBrains 仍有 2 年 40% 折扣

**风险提示**

- ⚠️ PS 造假证件会被永久封禁 GitHub 账号，绝对不要试
- ⚠️ 被拒后可换材料重新申请（换成带日期的缴费单成功率更高）
- ⚠️ 学生权益仅限非商业教育用途，别拿去跑商业生产

## 合规与安全提醒

- 每个平台通常**限一人一账号**，用小号/虚拟号批量注册属于违反服务条款，会被封号甚至连坐。
- 免费层多数**禁止商用或有明确的非生产限制**，上线前务必读一遍对应的 ToS。
- API Key 属于凭证，**不要提交到 Git 仓库**，建议只放环境变量。
- 绑卡类渠道（AWS/GCP/Azure/Oracle）请第一时间设置**预算告警**，避免试用到期后产生真实账单。
- 免费层的输入数据常被用于改进模型，**不要传敏感或涉密内容**。
